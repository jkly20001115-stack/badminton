# 第一人称羽毛球小游戏

这是根据 PRD 实现的浏览器端 MVP 原型，包含：

- 第一人称 3D 羽毛球场景。
- 单人模式：用户对战脚本电脑，电脑有随机失误概率。
- 双人模式：WebSocket 房间联机，两个用户可创建/加入同一房间。
- 15 分制、三局两胜、每球得分。
- WASD 移动、鼠标控制视角和击球方向、按住鼠标左键蓄力、松开左键击球。
- 对局中可暂停或退出；单人模式会暂停比赛，双人模式退出会离开房间。

## 启动

```bash
npm install
npm start
```

启动后打开：

```text
http://localhost:5173/
```

## 双人模式测试

1. 打开两个浏览器窗口或两个不同浏览器。
2. 第一个窗口进入双人模式并创建房间。
3. 第二个窗口输入房间号加入。
4. 双方点击准备后开始比赛。

## 快速进入单人模式

调试时可直接打开：

```text
http://localhost:5173/?mode=single&difficulty=normal
```

difficulty 可选：`easy`、`normal`、`hard`。
