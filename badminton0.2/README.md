# 我是超一流 - badminton0.2

这是根据 PRD 实现的浏览器端 MVP 原型，包含：

- 带固定亮色真实球馆背景、关节式火柴人对手和卡通羽毛球贴图的第一人称 3D 场景。
- 单人模式：鼠标上下左右控制击球角度，用户对战三档脚本电脑；普通与困难电脑会判断发球区、起跳和主动杀球。
- 淘汰赛模式：模拟奥运会、世锦赛、全英公开赛和世界巡回系列赛多轮晋级；赛事使用不同主题球馆，强度均高于困难模式，电脑随机击球失误率不超过 9%。
- 双人模式：本地试玩自动使用 WebSocket 房间；部署版本保留 Supabase Realtime 房间。
- 历史战绩：本机保存比赛记录，可查看、逐条删除或清空。
- 规则判定：发球站位、斜线发球区、短发球线、单打边线和击球出界判定。
- 普通击球采用加高弧线，抛物线弧高为此前版本的两倍；杀球轨迹保持下压。
- 15 分制、三局两胜、每球得分。
- WASD 移动、鼠标控制视角和击球方向、按住鼠标左键蓄力、松开左键击球、空格起跳、右键杀球、双击右键重杀。
- 对局中可暂停或退出；单人模式会暂停比赛，双人模式退出会离开房间。

## 启动

```bash
npm install
npm start
```

启动后打开：

```text
http://localhost:5173/
```

## 双人模式测试

1. 打开两个浏览器窗口或两个不同浏览器。
2. 第一个窗口进入双人模式并创建房间。
3. 第二个窗口输入房间号加入。
4. 双方点击准备后开始比赛。

## 快速进入单人模式

调试时可直接打开：

```text
http://localhost:5173/?mode=single&difficulty=normal
```

difficulty 可选：`easy`、`normal`、`hard`。
